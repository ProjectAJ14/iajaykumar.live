# Working in `src/`

Astro source for the site. Read the root `CLAUDE.md` and
`.claude/skills/coral-studio/SKILL.md` before changing anything here.

## File map

| Path | Owns |
|---|---|
| `pages/*.astro` | One file per route; each wraps its content in `Base` |
| `layouts/Base.astro` | `<title>` (`"<title> — Ajay Kumar"`, or the fixed home title when `title="Home"`), description, canonical, Open Graph card, font preconnects, pre-paint theme script, skip link, header, footer. Imports `styles/tokens.css`, then `../design-system/components/bundle.css`, then `styles/global.css`, in that order |
| `components/*.astro` | Astro markup for `design-system/components/` (Button, TopicChip, ThemeToggle, SiteHeader, SiteFooter, Hero, MediaFeature, TalkCard, LearningPathCard, ProjectCard, ArticleCard) plus `Arrow.astro` |
| `components/ext.ts` | `ext(href)`: external links get `target="_blank" rel="noopener noreferrer"` |
| `styles/global.css` | Site-layout utilities only; tokens via `var(--…)` only. Component styles are not here |
| `styles/tokens.css` | Generated by `scripts/tokens.mjs`; gitignored; a hook blocks edits |
| `content/index.ts` | Reads `../content/*.csv` with `?raw`, drops rows without real URLs, exports `articles`, `projects`, `talks`, `videos`, `courses`, `audio`, `LINKS`, `speakingMailto` |
| `content/paths.ts` | Editorial `learningPaths` (each lesson resolves to a real article by title prefix; a missing title fails the build) and `speakingTopics` |
| `content/csv.mjs` | RFC 4180 parser, tested by `scripts/csv.test.mjs` |

## How it fits

CSV row → adapter in `content/index.ts` (filters and shapes it) → page imports
the export → component renders it. Pages never read CSVs directly and never
hardcode a URL that belongs in `content/` or `LINKS`. An empty export means the
section is omitted, not shown with a placeholder.

Component styles come from `design-system/components/bundle.css`, imported
live; the bundle's own `@import` loads the fonts. Components must emit the
bundle's class names so its styles apply. Editing `bundle.css` changes the live
site; there is no copy to sync. Do not invent variants; if a page needs one,
change the design system first.

## Adding a page

1. Create `pages/<name>.astro` wrapping content in
   `<Base title="…" description="…" current="…">` with exactly one `<h1>`.
2. Add the label to the `nav` array in `components/SiteHeader.astro` (it feeds
   both the desktop nav and the mobile menu) and set `current` to that label.
3. Compose from existing components; follow `design-system/Pages.md`.
4. Add the route to the root `CLAUDE.md` repository map.
5. `npm run build` — `check-dist` must pass — then check the page with the
   `verify-site` skill.
