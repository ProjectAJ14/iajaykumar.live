# Reserved source folders

These folders are intentionally empty. They establish a shared vocabulary for the implementing agent without choosing a framework or adding application code.

- `components/` — reusable navigation, cards, chips, theme control, and footer.
- `pages/` — Home, Writing, Projects, Talks, About, and Contact page composition.
- `styles/` — semantic theme tokens, typography, spacing, and responsive layout.
- `content/` — adapters that read and validate the editorial CSV files in the repository's top-level `content/` folder.

If the chosen framework has a required route structure, adapt these folders and document the mapping in the main README.
