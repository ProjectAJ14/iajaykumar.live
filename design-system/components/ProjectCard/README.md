# ProjectCard

A product or open-source project, told problem-first.

**Consumer provides:** `name`, `problem` (one sentence), `outcome` (what it does/achieved), `role` only when confirmed by a source (“Creator”, “Maintainer”, “Contributor”), `tags` (stack, shown last in mono `cool-complement`), and verified `links.demo` / `links.docs` / `links.source`.

Links stay visible without hover. Hover lifts 4px. Separate “Products and tools” from “Open source and community” into different grids. Organization repos (JSON Viewer, Narad Muni, Vyuh) show no role until confirmed and never imply solo authorship. Screenshots only when real.
