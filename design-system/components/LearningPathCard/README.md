# LearningPathCard

A learning path on Learn and Home: what visitors will learn, then the real lessons that teach it.

**Consumer provides:** `index` (chapter number, shown as mono `02`), `title` — one of **Build full-stack products**, **Flutter and mobile**, **Developer tools** — `summary` (the outcome, not a syllabus), and `lessons` (each a real article, video, workshop, or talk with a working `href`).

Lessons reveal in place without animating height. The lesson-cards prop may fan 4–8px beside the section on hover/focus. **Don't** add progress bars, enrolment, or pricing: those belong to a future course card, only once a real course exists in `courses.csv`.
