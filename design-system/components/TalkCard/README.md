# TalkCard

One talk or workshop from `content/talks.csv`, for Speaking and the Home speaking section.

**Consumer provides:** `title`, `topic`, and only verified `event`, `date`, `recordingUrl`, `slidesUrl`. Missing fields and actions are omitted — the card never shows empty “Recording coming soon” slots.

The three-bar waveform (in `coral-accent`) reacts briefly on hover/focus; it is decorative and must never suggest audio is playing. Action links carry a coral cue line that extends 6–8px on hover/focus. Card lifts 4px.
