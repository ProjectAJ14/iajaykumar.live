# ArticleCard

A post from the linked Medium account (`content/articles.csv`), for Writing and Home.

**Consumer provides:** `title`, `href` (the CSV's canonical URL), `topic`, `date` (formatted “11 Sep 2024”), `source` (defaults to “Medium”; the whole card is one link).

Hover: coral underline grows under the title, arrow nudges 4px, background tints to `surface-raised`. The text never moves. Only posts from @ajay.kumar_14 — never other authors named Ajay Kumar.
